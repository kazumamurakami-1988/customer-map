# Morning Brief — 毎朝の予定＆要返信タスクまとめ

朝起きたときに、その日の動きと「返信が必要なもの」を1通にまとめて、本人の Slack DM に届けるための定例ルーチン。
スケジュール実行（毎朝6:00）から、または手動で「朝ブリーフ」と言われたときに走らせる。

## 前提・設定

- 本人 = 村上和磨。Slack user_id は `U09FJ733J0Y`（= 自分宛DMの channel_id）。
- 主なメール: `kazuma_murakami@empowerjp.com`（みちびきの `kazuma.murakami@michibiki.jp` 宛も本人）。
- タイムゾーンは JST（Asia/Tokyo）。日付は「今日」を JST で判定する。
- 文章は humanizer-ja の方針で書く。AIっぽい定型文（「〜が期待されます」「重要な示唆」等）は使わず、短く具体的に。

## 手順

必要なツールは ToolSearch で都度ロードする（MCPサーバIDはセッションで変わりうるので、名前で探す）。

### 1. 今日のカレンダー予定を取る

- まず `list_calendars` でカレンダー一覧を取り、本人の予定が入る次の2つを必ず `list_events` する（祝日カレンダーは除外）:
  - `kazuma_murakami@empowerjp.com`（エンパワー／primary）
  - `kazuma.murakami@michibiki.jp`（みちびき）
- 今日（JST 00:00〜23:59）の予定を時系列に並べる。終日予定・時間指定予定を分ける。
- 各予定: 開始〜終了時刻、タイトル、参加者（社外が居れば誰か）、Meet/Zoom リンクがあれば併記。
- **出欠の扱い**:
  - 自分の `responseStatus` が `declined`（不参加）の予定は、`※不参加` を添えて薄く（行末に注記）表示する。消さずに残す。
  - `needsAction`（未回答）の予定は `※出欠未回答` を添え、ブリーフ内で「出欠の返事を」と一言促す。
- **予定の重複・段取りチェック（重要）**: 時間が重なる予定、または「現地集合」と「オンライン（Meet/Zoom）」が近接する枠を見つけたら、`⚠️ 予定の注意` セクションを作り、ブリーフの予定一覧の直後（要対応より前）に出す。何時〜何時が、どう重なっているか、どちらが現地/オンラインかを1〜2行で書く。
- 注意: みちびきカレンダーの `accessRole` が `freeBusyReader` のときはタイトルが取れず時間帯のみになる。その場合は「（タイトル非公開）」と添え、共有権限の格上げを促す。

### 2. Gmail の「未返信」を拾う

- `search_threads` で次を確認:
  - `in:inbox is:unread newer_than:3d`（未読の新着）
  - 直近のスレッドで **最後の送信者が自分でない** もの = 自分のボールになっている＝要返信。
- ノイズ（GitHub/Instagram/Etsy/Notion通知、freeeの自動送信、配信失敗通知、メルマガ）は除外。
- 実務メール（取引先・社内・請求/契約・原稿やり取り）を優先。差出人・件名・要点1行・緊急度を出す。
- 判断に迷うものは `get_thread` で本文を確認してから載せる。

### 3. Slack の DM・メンションを拾う

- `slack_search_public_and_private` で次を確認（いずれも未返信＝自分が最後に返していないもの）:
  - `to:me is:thread` / 自分宛DM の新着
  - `to:<@U09FJ733J0Y>` のメンション
  - `after:` に前営業日の日付を入れて直近に絞る。
- 相手・チャンネル・要点1行・要返信かどうかを出す。

### 4. ブリーフを組み立てて自分宛DMに送る

`slack_send_message` で channel_id = `U09FJ733J0Y`（自分宛DM）に送る。Slackのmrkdwn記法で、こんな構成:

```
☀️ おはようございます。6/9(火)の予定とタスクです。

📅 今日の予定
・08:00-08:15 朝ミ（Zoom／安川さん）
・09:00-10:00 投資候補検討（九電・Teams）本店本館2F 211会議室
・15:30-16:30 Interop確認（海浜幕張・現地集合／本多さん）※出欠未回答
・16:00-17:00 みちびき様キックオフMTG（Meet／cast-er寺田さん）
・13:00-14:00 DCOS_PdM（Zoom）※不参加

⚠️ 予定の注意
・15:30〜17:00 が重なり気味。Interopは海浜幕張で現地集合、キックオフは16:00からオンラインMeet。
  → 現地に居ながら16:00のMeetに入れるか段取り要確認。Interopの出欠返事もどこかで。

⚠️ 要対応メール（1件）
・6/7送信「5稿_経済産業省施策」の添付がサイズ超過で不達。九電・黒川さんに届いたか確認 → 未達なら再送。

💬 要返信Slack（1件）
・堀さん DM → 第1稿をエンパワー共有に保存済み。確認・返事待ち。

⏰ 今日のおすすめ着手順: メール不達チェック → 15時台の重複の段取り → 堀さん返信
```

- 該当0件のセクションは「なし」と1行で書いて省略しない（見て安心できるように）。
- 件数が多い日は要返信を「今日中／今週中」で分ける。
- 最後に、その日いちばん効きそうな着手順を1〜2行だけ添える。媚びない、盛らない。

## 手動実行のとき

「朝ブリーフ」「今日の予定とタスク」等と言われたら、上の手順をそのまま実行する。
「送らずに見せて」と言われたら、Slack送信はせずチャットに同じ内容を出す。
